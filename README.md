# iPhone 13 Pro Redesign

Uma releitura da página de apresentação do iPhone 13 Pro desenvolvida com HTML, CSS e JavaScript.

O projeto começou como um estudo de reprodução de interface e evoluiu para uma versão própria, com modificações visuais, ajustes de experiência do usuário e melhorias de responsividade.

## Live Demo

https://lucas-vieira-sr.github.io/iphone13-pro-redesign/

## Sobre o Projeto

O objetivo deste projeto foi praticar desenvolvimento front-end através da recriação de uma landing page inspirada em um produto real, explorando conceitos de layout, estilização, responsividade e manipulação do DOM.

Além da implementação inicial, foram realizadas alterações de design para criar uma identidade visual própria e uma experiência mais personalizada.

## Funcionalidades

* Interface responsiva
* Seleção dinâmica de cores do produto
* Troca automática das imagens do dispositivo
* Transições suaves durante as alterações
* Navegação adaptada para dispositivos móveis
* Layout otimizado para diferentes tamanhos de tela

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

## Executando Localmente

Clone o repositório:

```bash
git clone https://github.com/Lucas-Vieira-SR/iphone13-pro-redesign.git
```

Acesse a pasta do projeto:

```bash
cd iphone13-pro-redesign
```

Abra o arquivo `index.html` em seu navegador.
